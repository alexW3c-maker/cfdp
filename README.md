# Custom Footer Dynamic Params

**Описание:**  
Плагин позволяет добавлять любое количество пользовательских параметров для футера сайта через административную панель WordPress. Для каждого параметра можно задать лейбл и тип (текст, телефон, email). Для поля "Телефон" реализована автоматическая маска и строгая валидация формата.

## Возможности

- Неограниченное количество настраиваемых полей
- Для каждого поля можно выбрать тип: текст, телефон, email
- Для телефона: автоматическая маска и строгая валидация формата `(000)-000-000-00`
- Удаление, добавление и редактирование полей прямо из админки
- Вывод значений только через шорткод `[cfdp_footer_params]`
- Стилизация футера через CSS-класс

## Установка

1. Скачайте и распакуйте архив с плагином.
2. Поместите папку `custom-footer-dynamic-params` в директорию `wp-content/plugins/` вашего сайта или через загрузку на странице добавления плагинов.
3. Активируйте плагин через меню "Плагины" в админ-панели WordPress.
4. Перейдите в раздел **Settings → Footer Dynamic Params** для настройки параметров.

## Использование

1. На странице настроек добавьте нужные параметры:
   - Укажите лейбл (название поля).
   - Выберите тип поля (текст, телефон, email).
   - Введите значение.
   - Для типа "Телефон" используйте только формат `(000)-000-000-00` — при вводе номер будет автоматически форматироваться.
2. Для удаления поля просто нажмите "Удалить" напротив нужной строки и сохраните изменения.
3. Для вывода параметров в футере (или в любом месте темы или записи) вставьте шорткод: `[cfdp_footer_params]`
